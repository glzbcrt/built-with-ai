Execution boundary and limitations

Run is explicit. Code executes in an opaque-origin iframe with scripts and local form events: no host DOM, credentials, storage, Node.js, popups, or privileged bridge. CSP blocks fetches, external resources, workers, frames, and form submissions; eval is disabled.

This is not full adversarial isolation: infinite loops can freeze the tab, memory is not capped, and self-navigation may issue a network request before the preview is removed. Do not run hostile code or use sensitive input. A public code runner needs separate process/container isolation and network controls.
