🪵 Parquet Explorer

Apache Parquet is a columnar file format built for efficient analytics. Explore how a query travels through its file structure: row groups contain column chunks, chunks contain pages, and metadata can help skip data that cannot match your filter.

1 · Try a query

Try SELECT *, or select columns such as SELECT product, amount FROM sales. Filters support a single equality, for example WHERE region = 'West' or WHERE amount = 42. Dataset columns: id, region, product, amount.

5 · What makes Parquet efficient?

🧱 Columnar layout

Each row group stores a separate chunk for every column. Queries that need only a few columns can avoid reading the rest.

📦 Pages

Column chunks are divided into pages, the encoding and compression units inside the file. This model shows page boundaries, but does not simulate byte-level reads.

🔎 Statistics

Row-group metadata can include values such as each column’s minimum and maximum. Here, an equality filter skips a group when its range cannot contain the searched value.

🧩 Encodings

Encodings represent values compactly before compression. Dictionary encoding can replace repeated values with small IDs; run-length encoding can represent repeated runs.

🗜️ Compression

Parquet supports codecs applied to data pages. The best choice depends on the workload: faster codecs may favor speed, while others may favor smaller files.

🧬 Nested schemas

Parquet schemas can describe typed, nested records such as lists and maps, not just flat tables.

What this explorer simplifies

Parquet is a file format, not a database or query engine. The dataset and file layout here are simulated in the browser; no Parquet file is generated. Row-group statistics only rule out groups whose minimum/maximum range cannot contain an equality value. A real engine may additionally use page indexes, dictionaries, Bloom filters, indexes, and other metadata. The example page boundaries group whole rows for clarity; actual pages belong to individual column chunks. Encoding and compression reduce bytes, but are not represented in the cell-value count.
