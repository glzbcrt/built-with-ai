What counts as a read?

This lab counts individual table cells accessed, not disk pages or bytes. For the row-oriented model, all columns in every row are read to find matching records and return the requested values. For the column-oriented model, an optional filter reads that column for every row, then reads requested columns only for matching rows. A filter column already read is not counted twice. Real database engines use indexes, compression, caching, and storage pages, so their physical I/O can differ.
